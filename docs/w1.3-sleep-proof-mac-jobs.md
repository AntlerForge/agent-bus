# W1.3 sleep-proof Mac jobs

The five Mac-only jobs use `StartCalendarInterval` plus `RunAtLoad`. macOS launchd
coalesces calendar events missed while asleep into a catch-up execution after wake.
The committed plist examples under `deploy/macos/` are the deployment authority.

A6 evaluates Tailscale peer availability before applying Mac freshness contracts:

- offline Mac: normal sleep; freshness checks are suspended;
- online Mac: reporter, mount, runtime check and sync outcomes must meet their
  existing semantic windows;
- authority violations such as unexpected retired-ledger writes are never
  suppressed.

This keeps lid-close silent without treating a stopped job on an awake Mac as
healthy. No job wakes the laptop and no inbound Mac service was added.

## Observation gate

The implementation was deployed and all five jobs completed with exit code 0 on
2026-07-20. Completion still requires one real sleep/wake catch-up observation per
job and two consecutive overnight sleeps with zero false cards. Verify using the
live plist state, Mac outcome markers, A6 Mac snapshot, and A6 card store; do not
close cards manually.
