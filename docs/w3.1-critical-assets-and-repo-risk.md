# W3.1 critical assets and repository-risk sweep

The versioned inventory is `config/critical-assets.v1.yaml`. It records current protection
without treating a live mount or dirty working copy as a backup. Home Assistant configuration
is explicitly unprotected until a verified scheduled HA backup lands in a Borg-protected path.

The existing `com.antlerforge.agent-bus-outcome-reporter` remains the only Mac footprint.
On each 15-minute reporter run, `outcome-truth-mac-report.sh` refreshes
`~/Library/Application Support/Agent Bus/repo-risk/latest.json` only when the cache is absent
or seven days old. The sweep recursively discovers Git repositories below `~/Developer`, uses
read-only Git status/ref/fsck queries, and proves logical Git signatures unchanged. It creates
no commit, branch, remote, fetch or push. The Markdown sibling is the ranked human view.

A6 receives the report inside `runtime/outcome-truth/mac-snapshot.json`. The decision queue
projects every finding as a proposal with a prepared one-line action; it does not execute that
action. The sentinel hard check allows eight days, giving the weekly refresh one day of margin.

First live sweep on 2026-07-19 scanned 36 repositories and found 32 risks: 19 dirty over seven
days, 2 ahead, 18 without remotes and 7 corrupt. The 2026-07-18 oracle reconciled fully:
agent-bus is clean, knowledge-vault still has 18 dirty paths, EnergyPoints is ahead by 9, all
five named no-remote repositories and all four named corrupt repositories remain visible.
New evidence also identifies corruption in EnergyPoints, ForgeV1 and knowledge-vault.

Reversal: remove the cache-refresh block from `outcome-truth-mac-report.sh`, the `repo_sweep`
projection from the Mac probe, `collectRepoRisks` from the decision queue, and the one sentinel
matrix check. Then delete only `~/Library/Application Support/Agent Bus/repo-risk/`. No
LaunchAgent, credential, port or source repository is added or changed by the feature.
