# Support

Agent Bus is a small personal open-source project maintained by one person with a
full-time job.

Issues, feedback, test reports, and improvement ideas are welcome, especially when they
include clear reproduction steps and the platform details involved. I cannot commit to
responding quickly, implementing requested features, or providing individual setup
support.

## Good Issue Reports

Please include:

- operating system and version;
- Node.js version;
- Claude/Codex/agent host involved;
- exact command or MCP configuration used;
- what you expected to happen;
- what actually happened;
- any relevant log output with secrets removed.

## Scope

I am most likely to look at:

- setup failures affecting the documented quick start;
- bugs in mailbox/thread handling;
- clear documentation gaps;
- small pull requests that preserve the local-first design.

Feature requests are fine, but they may sit for a while.
